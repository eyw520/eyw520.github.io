Real Analysis

Continuity Is a Game

Epsilon and delta stop being an incantation the moment you notice there are two players. Take the second move, and watch where you can no longer answer.

Everyone is taught that a continuous function is one you can draw without lifting the pen, and then everyone is handed a definition with two Greek letters in it that appears to be about something else entirely. It is about the same thing. It is just phrased as a game, and nobody says so.

There are two players. The first names a tolerance — how close to the function's value at your point the output has to stay. That is ε, and they may make it as mean as they like. The second must then name a window around the point, narrow enough that the function does not escape the tolerance anywhere inside it. That is δ.

The function is continuous at that point if the second player can always answer. Not if they can answer easily, and not if the same answer keeps working — only that no challenge leaves them stuck.

Below you are the second player, and the answer is played for you: the green window is always the widest one that works. Set a mean tolerance and drag the point along the curve, and you can feel where the game gets hard — the answer narrows sharply where the function is steep, and opens up where it is flat. That is all continuity is. Steepness makes the game harder; only a genuine break makes it unwinnable.

Then find the cliff, and stand on it. Below the height of the drop there is no answer at all: however narrow a window you choose, it contains points on the far side of the cliff, and they are further away than the tolerance allows. The game is lost, and that is what a discontinuity is — not a jump you can see, but a challenge you cannot meet.

The second figure is where this stops being a definition and starts being a subject. It plays the same game at every point of the window at once and draws how wide an answer each one gets. If that curve stays above zero, one single δ answers the challenge everywhere, and the function is called uniformly continuous — a much stronger thing, and the property that nearly every theorem about integration actually needs. If it dives to zero, then every point has an answer and no answer serves them all.

Try the same parabola on the two different windows. The function has not changed at all; the window has. Then try the wiggling one, which crosses zero infinitely often near the origin and looks far worse behaved than anything else here — and is uniformly continuous, because its window is closed and bounded. That is Heine and Cantor's theorem, and the picture is the proof's whole idea: on a closed bounded window there is nowhere for the answer to run away to.

The easiest curve there is, and the game is still not uniform in difficulty: flat at the bottom, where almost any window works, and steep at the ends, where the answer narrows. Nothing is ever unwinnable.

Continuity at a point asks only that some answer exists there, and it is a question about one place at a time. Uniform continuity asks for one answer that serves every place at once — the lowest point of the second curve, staying above zero. The two come apart exactly when the window is left open at an end, or stretched without bound; close it and bound it, and they are the same thing.
